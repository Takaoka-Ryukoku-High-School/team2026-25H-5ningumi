# たべものカメラ

Python と Flet で作った、食べものに少しずつ慣れるためのミニゲームです。気になる食べものをカメラで撮影するか写真を選び、見たり、においを感じたりした小さな一歩を記録できます。味見は任意です。写真と記録はユーザーのホームディレクトリに保存されます。

## 起動方法

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

起動するとブラウザでアプリが開きます。スマートフォンでは「写真を撮る・選ぶ」からカメラまたは写真ライブラリを利用できます。
