# たべものカメラ

Python と Flet で作った、食べものに少しずつ慣れるためのミニゲームです。気になる食べものをカメラで撮影するか写真を選び、見たり、においを感じたりした小さな一歩を記録できます。味見は任意です。写真と記録はユーザーのホームディレクトリに保存されます。

記録した食べものごとに「きょうの気づき・感想」を入力して保存できます。

「一日の食事まとめ」では、食べたものを朝食・昼食・夕食ごとに記録し、日付を切り替えて見返せます。入力した内容を保存する機能で、栄養成分や量の推定は行いません。

食べものを記録したり練習ステップを進めたりして5ポイント獲得するごとにレベルアップし、新しい称号を獲得できます。現在の称号と次のレベルまでの進み具合はトップ画面に表示されます。

食事を記録するか、食べものの練習を記録した日が連続するとストリークが続きます。トップ画面に現在の連続日数と過去最高を表示します。

食事を記録するとキャラクターが経験をためて成長します。記録回数に応じて姿や名前が変わり、次の成長までの進み具合も表示します。成長は食べた量や内容ではなく、記録した回数に基づきます。

キャラクターのデザインは「かわいい」「かっこいい」「面白い」「真面目」から選べます。選んだデザインは保存され、成長段階に応じて姿や名前も変わります。

キャラクターのアイコンは絵文字一覧から選ぶか、JPG・PNG・WEBP・GIF画像（5MB以下）をアップロードできます。アイコン設定は保存されます。

各記録では「食べる練習」として、写真を見る・近くで見る・においを感じるなど、今日できそうな一歩を自分で選んで日付付きで記録できます。味見や食べることは任意で、今日は休む選択もできます。アレルギーや安全上の懸念がある食べものは試さず、家族や医療・栄養の専門家に相談してください。

各記録の「ほかのレシピを探す」から、入力した食べもの名でレシピをウェブ検索できます。写真の料理を自動で判定する機能ではありません。

各記録の「栄養成分を見る（文部科学省）」から、[食品成分データベース](https://fooddb.mext.go.jp/)で料理や材料の栄養成分を確認できます。写真から栄養やアレルギーを判定するものではなく、調理方法や量によって実際の成分は異なります。体調や食事制限については医療・栄養の専門家に相談してください。

部屋コードを共有して、友だちと2人でポイント対戦もできます。対戦中に食べものを記録するかステップを進めると1ポイントです。対戦ルームとスコアはアプリ稼働中のみ保持されます。別の端末から対戦する場合は、両方の端末が同じアプリサーバーに接続できる必要があります。アカウント機能はないため、記録と写真はアプリサーバーの保存先に保存されます。共有サーバーで使う場合は、個人情報が写った写真を登録しないでください。

## 起動方法

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

起動するとブラウザでアプリが開きます。スマートフォンでは「写真を撮る・選ぶ」からカメラまたは写真ライブラリを利用できます。
